# Privé — le garde-fou

> Cette fiche n'entre dans AUCUNE vue. Elle existe pour dire pourquoi.

Le canon ne contient volontairement rien d'intime : santé, procédures
judiciaires, adresses précises, montants, la vie des proches dans le
détail — tout cela vit dans le cerveau (`life/cerveau/`), qui reste LA
source du vivant personnel, avec ses propres règles de confidentialité.

Avant toute publication un jour d'une vue publique, la relecture part
d'ici : le privé ne sort jamais, même déguisé en anecdote.
